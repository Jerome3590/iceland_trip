# Iceland Ring Road Expedition Map

Static site: phase-based Ring Road route (May 2026), MapLibre map, EV charging tab, itinerary and Route 1 notes.

Open `index.html` locally or deploy the folder to any static host (S3, CloudFront, etc.).

**Dashboard URL:** https://jerome3590.github.io/iceland_trip/
